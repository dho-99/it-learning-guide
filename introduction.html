スマホで始める
IT入門

PCがなくても大丈夫。7つの学習セクションから、自分のペースでITの世界に触れてみよう。

スマートフォンのみ無料ツール中心1セクション20〜55分未経験者向け
このガイドの使い方

このガイドは「7つの学習セクション」でできています。1日に1つ進める必要はありません。自分のペースで、好きなところから始めてください。

  • 興味のあるセクションから始めてもかまいません。
  • 分からないところは飛ばしたり、後から戻ったりしてOKです。
  • 各セクションのタイトル横にある「前提」は、先に取り組んでおくと理解しやすいセクションを示します。前提があるセクションで迷ったら、前提のセクションに戻ってみてください。
  • 全部を暗記する必要はありません。「何をするものか」「どんな場面で使うか」が少し分かれば十分です。

スマートフォンではコード入力やターミナル操作がしづらい場合があります。その場合は、説明を読む・コードを眺めるところまででOK。無理にアカウント登録やアプリのインストールをする必要はありません。

このガイドで大切にしたいこと

全部を覚える必要はありません。

今回の目的は、資格を取ることでも、すぐに仕事ができるようになることでもありません。

  • 知らないことを調べるのが苦にならないか
  • 試行錯誤して答えを見つけるのが面白いか
  • もう少し続けてみたいと思えるか

まずは1つのセクションを、気軽に試してみましょう。興味が続いたら、その次にPC環境や本格的な学習方法を考えれば大丈夫です。

所要時間の目安

スマホで調べ、複数の説明を読み比べ、自分なりに理解するには時間がかかります。次の時間はあくまで目安です。じっくり時間をかけて構いません。

  • キーワード調査：15〜25分
  • 内容の整理・理解：10〜15分
  • クイズや実践：10〜15分

セクションによって含まれる内容が異なるため、各セクションの目安時間は異なります。

7つの学習セクション

セクション 1｜ITの仕事を知る前提：なし
インフラ・開発、Webサイト、サーバー

ゴール：IT業界にどんな仕事があるか、ざっくり説明できる。

セクション 2｜Linuxに触れる前提：なし
Linuxとは何か、pwd・ls・cd

ゴール：基本コマンドの意味を調べ、目的に合うものを選べる。

セクション 3｜Linuxコマンドを知る前提：セクション2
mkdir・touch・cat・grep・mv

ゴール：目的に合うコマンドを選び、ファイル操作の流れを考える。

セクション 4｜Pythonの基礎前提：なし
Python、プログラミング言語、インタープリタ・コンパイラ、Hello World

ゴール：Pythonやプログラム実行の関連キーワードを整理し、Hello Worldを実行してコードと結果の関係を確認できる。

セクション 5｜プログラミングの基本前提：セクション4
変数、数値と文字列、if文

ゴール：変数と条件分岐の基本を理解する。

セクション 6｜繰り返し処理を知る前提：セクション5
for文、繰り返し、簡単な計算

ゴール：繰り返し処理の流れを追えるようになる。

セクション 7｜振り返り前提：なし（取り組んだ範囲でOK）
面白かったこと、難しかったこと、次に学びたいこと

ゴール：興味を持ったことと次に試したいことを言葉にする。

学習を始める前に

  • スマートフォンのブラウザ（Safari / Chrome）を使います。
  • サイトが英語表示の場合は、ブラウザの翻訳機能を使って構いません。
  • 学習サイトの画面構成は変更されることがあります。リンク先で該当する見出しを探してください。
  • 個人情報、パスワード、勤務先の情報などは、学習サイトやAIチャットに入力しないでください。
  • コマンドは意味を確認してから試します。今回は削除・初期化などの操作は行いません。

各セクションの詳細タスク

01

ITの仕事とWebの仕組みを知る 前提：なし

目安：25〜40分｜キーワード調査15〜25分／整理・理解10〜15分

このセクションの目的：いくつかのキーワードを手がかりに、ITの仕事やWebサイトの仕組みを自分なりに調べ、言葉同士のつながりを考える。

使うもの
スマートフォンのブラウザ（Safari / Chrome）と検索エンジン。調べ方や検索する順番は自由です。

タスク1：ITの仕事に関するキーワードを調べる（約8〜12分）

次のキーワードを手がかりに、気になったものから調べてみましょう。検索ワードの組み立て方や、見るサイトは自分で選んで構いません。

キーワード
  • インフラエンジニア
  • 開発エンジニア
  • システム運用・保守
  1. それぞれがどんな仕事なのか、自分が分かりやすい説明を探す。
  2. 「何を扱う仕事か」「誰の役に立つか」「仕事同士にどんな関係がありそうか」を考える。
  3. 調べた内容を、箇条書き・図・文章など好きな方法で整理する。

タスク2：Webサイトの仕組みに関するキーワードを調べる（約8〜12分）

キーワード
  • Webサイト
  • ブラウザ
  • サーバー
  • リクエスト
  • レスポンス
  1. それぞれの言葉が何を指すのか、自分なりに調べる。
  2. 言葉同士がどのようにつながっているのか、調べた情報をもとに考える。
  3. 普段スマートフォンでWebサイトを開くとき、裏側でどんなやり取りが起きていそうか、好きな方法でまとめる。

タスク3：内容を整理して理解を確認する（約10〜15分）

最初から正確な説明を作る必要はありません。複数の説明を見比べて、自分が納得できる形に整理してみましょう。分からない言葉が出てきたら、その言葉を新しいキーワードとして調べてみてください。

このセクションのゴール：ITの仕事やWebサイトの仕組みについて、キーワード同士の意味やつながりを自分なりに説明できる。
02

Linuxに触れる 前提：なし

目安：25〜40分｜キーワード調査15〜25分／クイズ10〜15分

このセクションの目的：Linuxとコマンドラインの概要を知り、基本コマンドの意味を調べたうえで、目的に合うコマンドを考える。

使うサイト：Linux Journey – Getting Started
Linuxの基礎を学ぶ教材。英語表示の場合はブラウザの翻訳機能を使ってください。

タスク1：Linuxとコマンドラインについて調べる（約7〜10分）

  1. Linux Journeyで「Getting Started」や「What is Linux?」にあたるレッスンを探す。
  2. Linuxが何なのか、どのような機器・サービスで使われているのかを調べる。
  3. 「Command Line」または「The Shell」にあたる説明を探し、画面上のボタンやアイコンで操作する方法との違いを考える。

タスク2：3つのコマンドの意味を調べる（約8〜15分）

次のコマンドを1つずつ調べ、「何をするコマンドか」「どんな場面で使うか」を自分の言葉でメモしましょう。

調べるコマンド

pwd　ls　cd

タスク3：目的に合うコマンドを答えるクイズ（約10〜15分）

次の操作をしたいとき、どのコマンドを使えばよいでしょう？ タスク2で調べた内容をもとに、まず自分で答えてみましょう。必要なら複数のコマンドを順番に使います。

  1. 今、自分がどのフォルダにいるのか確認したい。
  2. 今いるフォルダの中に、どんなファイルやフォルダがあるか一覧で見たい。
  3. 「documents」というフォルダに移動したい。
  4. 移動したあと、本当に目的のフォルダに移動できたか確認したい。

答えはコマンド名だけでなく、「なぜそのコマンドを選んだのか」も一言添えてみましょう。

この日はコマンドを実行できなくても問題ありません。調べて意味を理解し、目的に合わせて選べることが目標です。

このセクションのゴール：pwd・ls・cdの役割を理解し、やりたい操作に応じて使うコマンドを選べる。
03

Linuxコマンドを知る 前提：セクション2

目安：25〜40分｜キーワード調査15〜25分／クイズ・実践10〜15分

このセクションの目的：ファイルや文章を扱うコマンドの意味を調べ、やりたい操作に応じてコマンドを選ぶ練習をする。

使うサイト：Linux Journey – Command Line
コマンドラインのレッスン一覧。スマホで操作しにくければ、説明を読むだけでも構いません。

タスク1：5つのコマンドの意味を調べる（約15〜25分）

教材内または検索エンジンで、次のコマンドをそれぞれ調べましょう。「何をするためのものか」「どんなときに使いそうか」を自分の言葉でメモします。

調べるコマンド

mkdir　touch　cat　grep　mv

mvはファイルやフォルダの移動・名前変更に関係するコマンドです。まずは自分で調べ、どんな使い方ができるか確認してみましょう。

タスク2：やりたい操作からコマンドを選ぶクイズ（約7〜10分）

次の場面で使うコマンドは何でしょう？ 1つでできるものも、複数を組み合わせるものもあります。コマンド名と、選んだ理由を答えてみましょう。

  1. 「practice」という名前の新しいフォルダを作りたい。
  2. 「memo.txt」という空のファイルを新しく作りたい。
  3. 「memo.txt」の中に書かれている内容を画面で確認したい。
  4. たくさんの文章が書かれたファイルから、「error」という単語が含まれる行だけを探したい。
  5. 「memo.txt」というファイルの名前を「memo_old.txt」に変更したい。
  6. 「memo.txt」を「archive」というフォルダの中へ移動したい。

タスク3：コマンドを組み合わせると？（約3〜5分）

次の操作を実現するには、どのコマンドをどんな順番で使えばよいか考えてみましょう。

「practice」というフォルダを作り、その中に「memo.txt」というファイルを作って、最後にファイルの中身を確認する。

コマンドの順番を自分で組み立ててみましょう。答えを先に見ず、タスク1で調べた意味から予想するのがポイントです。

今回は用途を理解することが目的です。スマートフォンで実行環境を用意する必要はありません。見慣れないコマンドを意味を確認せずにコピーして実行しない習慣も大切です。

このセクションのゴール：mkdir・touch・cat・grep・mvの役割を理解し、やりたい操作に合わせてコマンドを選べる。
04

Pythonの基礎 前提：なし

目安：35〜55分｜キーワード調査15〜25分／整理・理解10〜15分／実行10〜15分

このセクションの目的：Pythonやプログラムの実行に関するキーワードを自分で調べて関係を整理し、そのうえでPythonのコードを実際に実行して、コードと実行結果の関係を確認する。

使うもの（タスク1）
スマートフォンのブラウザと検索エンジン。調べ方や見るサイトは自由です。Programizはタスク2で初めて開きます。

タスク1：キーワードから調べる（調査15〜25分＋整理10〜15分）

次のキーワードを、まず自分で調べてみましょう。コードを動かすのは、調べたあとです。

キーワード
  • Python
  • プログラミング言語
  • インタープリタ
  • コンパイラ
  • プログラムの実行
  1. それぞれの言葉が何を指すのか、複数の説明を見比べながら調べる。
  2. 言葉同士の関係を考える。たとえば「Pythonとプログラミング言語の関係は？」「インタープリタとコンパイラは何が違う？」「書いたプログラムは、どのようにして実行されるの？」など。
  3. 調べた内容を、箇条書き・図・文章など好きな方法で整理する。

タスク2：Programizで実行する（約10〜15分）

ここで初めて使うサイト：Programiz – Python Online Compiler
ブラウザ上でPythonコードを入力して実行できるサイト。インストールやアカウント登録なしで試せます。
  1. Programizのページを開き、コード入力欄（Editor / main.py）を探す。
  2. 最初から入っているサンプルコードを消して、次の1行を入力する。
print("Hello World")
  1. 「Run」ボタンを押して実行する。
  2. 出力欄（Output）に何が表示されたか確認する。
  3. 書いたコードと、表示された結果の関係を考える。「どの部分が、どの表示につながっているか？」
  4. 表示する言葉を好きな言葉（例："こんにちは！"）に変えて、もう一度実行し、結果がどう変わるか確認する。
  5. タスク1で調べたキーワード（プログラムの実行、インタープリタなど）と、いま起きたことを結びつけて考えてみる。

スマホで入力欄が扱いづらい場合は、ページ内のサンプルコードを読んで、printが「画面に表示する命令」だと分かればOKです。

このセクションのゴール：Python・プログラミング言語・インタープリタ・コンパイラ・プログラムの実行の関係を自分なりに説明でき、Hello Worldを実行してコードと結果の関係を確認できる。
05

プログラミングの基本 前提：セクション4

目安：20〜30分｜実践10〜15分／整理・理解10〜15分

このセクションの目的：プログラムが情報を保存し、条件によって動きを変えられることを知る。

使うサイト：Programiz – Python Online Compiler

タスク1：変数を知る（約6〜10分）

変数は、値を入れておく名前付きの箱のようなものです。次のコードを入力して実行します。

name = "Hanako"
age = 30

print(name)
print(age)

nameには文字列、ageには数値を入れています。出力結果がどうなるか確認しましょう。

タスク2：数値と文字列の違い（約5〜8分）

print(10 + 5)
print("10" + "5")

上は数値の足し算で15、下は文字列の連結で105になります。見た目が似ていても、数値と文字列では扱いが違うことを確認します。

タスク3：if文による条件分岐（約9〜12分）

if文は「もし条件に当てはまるなら、この処理をする」という命令です。

age = 20

if age >= 18:
    print("成人です")
else:
    print("18歳未満です")

age = 20を age = 15 に変えて実行し、表示が変わることを確認します。

このセクションのゴール：変数に情報を入れ、if文で条件によって処理を分けられると理解する。
06

繰り返し処理を知る 前提：セクション5

目安：20〜30分｜実践10〜15分／整理・理解10〜15分

このセクションの目的：同じ処理を何度も書かず、繰り返し命令でまとめられることを知る。

使うサイト：Programiz – Python Online Compiler

タスク1：for文を知る（約4〜6分）

for文は、決められた回数やデータの数だけ、同じ処理を繰り返すために使います。

タスク2：3回繰り返してみる（約6〜8分）

for i in range(3):
    print("こんにちは")

実行して「こんにちは」が3回表示されることを確認します。range(3)は3回分の繰り返しを作ります。

タスク3：数字を表示する（約6〜8分）

for i in range(1, 6):
    print(i)

1から5まで順番に表示されます。range(1, 6)は1以上6未満、つまり1〜5を表します。

タスク4：簡単な合計を計算する（約4〜8分）

total = 0

for i in range(1, 6):
    total = total + i

print(total)

1＋2＋3＋4＋5の合計である15が表示されれば成功です。

このセクションのゴール：for文で処理を繰り返せることと、小さなプログラムの流れを追えることを知る。
07

振り返り 前提：なし（取り組んだ範囲でOK）

目安：20〜30分｜整理・理解10〜15分／振り返り10〜15分

このセクションの目的：ここまで取り組んだ内容を振り返り、次に何を学びたいか考える。取り組んでいないセクションがあっても問題ありません。

タスク1：できたことを確認する（約5〜8分）

タスク2：3つの質問に答える（約10〜15分）

  1. 一番面白かった内容は何？
  2. 一番難しかった内容は何？ それは「説明が難しい」のか「操作が難しい」のか？
  3. もう少し調べてみたい、試してみたいと思ったことは何？

タスク3：次の方向性を考える（約5〜8分）

興味に応じて、次のような方向を考えてみましょう。

  • Linuxやサーバーが気になる：インフラエンジニア、クラウド、ネットワークなど。
  • コードを書くのが面白い：プログラミング、Web開発、業務自動化など。
  • 人の困りごとを解決するのが好き：ITサポート、ヘルプデスク、業務改善など。
  • まだ分からない：それで大丈夫。別のIT職種を調べたり、気になったセクションをもう一度試したりしてみましょう。
このセクションのゴール：得意・不得意を決めつけず、「何に興味を持ったか」「次に何を試したいか」を言葉にする。
